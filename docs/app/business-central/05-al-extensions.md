# Business Central: AL Extensions

AL is the language used to develop BC extensions. Extensions can add or extend pages, tables, business logic, and other objects. Beginners can start with these common object types: **Table** stores data structures, **Page** presents an interface, **Codeunit** contains business logic, and **Report** produces reports.

Requirements determine whether AL is needed. If an external system only needs to read or write existing business data, assess the standard APIs first. If BC's internal behavior or interface must change, assess an extension.

References: [AL development overview](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-dev-overview) and [getting started with AL](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-get-started).
