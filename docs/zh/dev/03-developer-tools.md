# 开发机、IDE、命令行工具与本地环境

开发机只承载源码、测试数据和临时构建结果，不保存生产凭据或未脱敏的业务数据。团队可使用受管理的 macOS、Windows 11 + WSL2 或 Ubuntu 24.04 LTS；具体设备由 IT 资产管理分配。本页规定工具与本地环境的最低要求，不强制所有项目使用同一种语言。

## 通用工具

| 工具 | 用途 | 版本规则 |
| --- | --- | --- |
| Git、GitHub CLI | 获取代码、创建 PR、查询仓库 | 使用受支持版本，登录使用个人账号 |
| VS Code 或项目认可的 IDE | 编辑、调试与代码评审 | 扩展来源可追溯，团队共享推荐清单 |
| Azure CLI | 查看开发资源、调试身份与部署 | 使用个人身份，仅授予 Dev 访问 |
| Docker/Podman | 本地构建与运行容器 | 与目标平台架构兼容，验证镜像可运行 |
| .NET SDK、Bun/Node、Python | 对应项目开发 | 以仓库清单和锁文件为准，不依赖机器全局最新版 |
