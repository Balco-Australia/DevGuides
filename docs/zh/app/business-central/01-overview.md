# Business Central：概览与术语

Business Central 是用于管理财务、采购、销售、库存等业务的 ERP 系统。了解它时，可以先区分以下概念：

| 术语 | 入门理解 |
| --- | --- |
| 租户（Tenant） | 组织使用 Microsoft 云服务的身份边界。 |
| 环境（Environment） | BC 的一个运行实例，例如生产环境或沙盒环境。 |
| 公司（Company） | 环境内承载一套业务数据的单位。 |
| 扩展（Extension） | 在标准 BC 功能之外增加功能的应用包。 |
| API | 外部系统读取或写入 BC 业务数据的接口。 |

学习时建议先看实际业务流程，再了解环境和权限，最后选择扩展或 API 的开发方式。

参考：[Business Central 官方文档](https://learn.microsoft.com/dynamics365/business-central/)。
