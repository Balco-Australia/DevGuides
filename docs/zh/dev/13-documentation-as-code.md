# 文档即代码、知识库、模板与归档

研发文档与代码一起版本管理、评审和发布。每日构建将 `dev` 对应的文档发布到内部预览站点；正式 CD 将发布版本对应的文档发布到正式站点。两次发布都要记录文档来源提交及站点地址，避免应用与文档版本不一致。

## 文档放置与最低要求

| 文档 | 位置与用途 |
| --- | --- |
| 仓库 `README.md` | 系统用途、负责人、本地启动、测试与部署入口 |
| 需求与验收记录 | 关联工作项，写明目标、范围和验收标准 |
| 架构与决策记录（ADR） | 组件关系、数据流、依赖及关键取舍 |
| API 与数据契约 | 接口、认证、错误、兼容性和迁移规则 |
| 操作与运维手册 | 部署、监控、故障排查、备份与回滚 |
| 发布说明 | 版本、变更、迁移、已知问题与回滚入口 |

系统专属文档放在应用仓库 `docs/`，跨项目共用规范放在本 VitePress 站点。

## 自动构建与发布

| 时机 | 文档来源 | 发布位置 | 
| --- | --- | --- | 
| CI | 无 | 无 |
| 每日集成测试 | 通过 CI 与集成测试的 `dev` 提交 | 内部预览站点 | 
| CD | 已部署的发布版本 | 正式文档站点 |
