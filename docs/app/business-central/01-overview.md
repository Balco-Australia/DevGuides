# Business Central: Overview and Terminology

Business Central is an ERP system for managing finance, purchasing, sales, inventory, and other operations. Start by distinguishing these concepts:

| Term | Introductory meaning |
| --- | --- |
| Tenant | The identity boundary for an organization's Microsoft cloud services. |
| Environment | A running instance of BC, such as production or sandbox. |
| Company | A unit that holds a set of business data within an environment. |
| Extension | An app package that adds functionality beyond standard BC features. |
| API | An interface through which external systems read or write BC business data. |

When learning BC, start with real business processes, then understand environments and permissions, and finally choose between extensions and APIs for development.

Reference: [Business Central documentation](https://learn.microsoft.com/dynamics365/business-central/).
