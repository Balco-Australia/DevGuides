# 共享配置、密钥服务与凭据使用

配置分为**公开配置、受限配置和密钥**。变量名、默认值和用途写在仓库；真正的密钥不进入 Git、镜像、文档、日志或前端构建结果。

## 存放规则

| 类型 | 示例 | 存放位置 |
| --- | --- | --- |
| 公开配置 | API 公共地址、Entra tenant/client ID、功能开关 | GitHub Variables、环境配置文件或 Azure App Settings |
| 受限配置 | 内部端点、站点 ID、非公开资源名称 | 受权限控制的环境配置；不要在公开仓库披露 |
| 密钥 | Client secret、API key、连接密码、证书私钥 | Azure Key Vault；本地使用受保护的密钥存储 |
